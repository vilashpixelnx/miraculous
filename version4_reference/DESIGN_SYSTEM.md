# MIRACULOUS v4 – PREMIUM MUSIC STREAMING UI DESIGN SYSTEM

Reference screenshot (Home page, approved direction): `home_reference.png` (same folder).

## 1. Brand identity
Brand: Miraculous. Premium music streaming, modern 2026, neon futuristic, soft glassmorphism, immersive audio, elegant balanced layout.

## 2. Color palette
- Deep Navy: #101638
- Midnight Blue: #151947
- Royal Purple: #5934C8
- Electric Purple: #8B35F5
- Neon Pink: #F02DBD
- Hot Pink: #FF4FA8
- Electric Cyan: #16D9F5
- Light Lavender: #EAE5FF
- Soft White: #F9F7FF
- Pure White: #FFFFFF

## 3. Gradients
- Primary Brand: linear-gradient(110deg, #FF4FA8 0%, #C837E8 48%, #6548FF 100%)
- Neon Audio: linear-gradient(90deg, #8B35F5 0%, #F02DBD 50%, #16D9F5 100%)
- Hero Background: linear-gradient(110deg, #171B4B 0%, #29206A 45%, #111638 100%)
- Light Content Background: linear-gradient(110deg, #FFFFFF 0%, #F2EDFF 55%, #E9E1FF 100%)
- Sidebar Background: linear-gradient(180deg, #F3EEFF 0%, #E5DCFF 100%)

## 4. Typography — Poppins (Google Fonts)
Weights: hero 800, section headings 700, card titles 600, nav 500, body 400, small labels 500.
Colors: main heading #FFFFFF, gradient heading #F04DCB, hero description #E7E2FA, section headings #19152C, song titles #17142B, artist names #716B89, navigation #17142B, player text #FFFFFF.

## 5. UI effects
- Glass: background rgba(255,255,255,0.12); backdrop-filter blur(20px); border 1px solid rgba(255,255,255,0.22)
- Neon glow: box-shadow 0 0 25px rgba(240,45,189,0.45)
- Radius: cards 14–18px, buttons 999px, player 22px

## 6. Rules
- Keep Miraculous branding and logo; Poppins everywhere
- Same visual identity as the reference screenshot; no colors outside the palette
- Subtle neon glow (not excessive), smooth transitions, polished hovers
- Strong text contrast; premium, modern, clean

## Layout seen in reference (Home)
- Light lavender sidebar: logo, Home (active pink pill), Discover, Albums, Artists, Radio, Podcasts, Playlists; "Your Library": Liked Songs, Downloads, My Playlists (+); Premium upgrade card at bottom
- Top bar on hero: glass pill search "Search for songs, artists, albums and more...", notification bell, avatar "Hello, Vilash"
- Dark hero: "FEEL THE MUSIC" letter-spaced label, "Music is an Experience." (Experience in gradient), subtitle, Listen Now gradient pill + heart circle button, waveform + shuffle/prev/pause/next/repeat controls, girl with headphones + neon ring + wave lines
- Light content: "Trending Now" card slider (6 cards, arrows, View All), "Mood Playlists" tiles (Focus Flow, Chill Vibes, Workout Beats, Night Drive, Romantic Hits, Party Mix)
- Dark glass bottom player: cover, title/artist, like, controls, neon waveform seek, time, volume slider, queue icon
